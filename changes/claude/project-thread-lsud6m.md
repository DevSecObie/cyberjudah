- Security (audit C2): every workflow job that reads a Cloudflare, R2, YouTube, TranscriptAPI, Anthropic or GitHub token now runs in the `automation` environment. Once the owner limits that environment to `main` and moves those secrets into it, a push to any other branch can no longer read them. Nothing changes until then: GitHub creates the environment on first use, and a job still sees the repository secrets until they are deleted. `data.yml` keeps its `production` environment.
